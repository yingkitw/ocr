## Blocked — what's next

The training pipeline is end-to-end but the bundled model is currently a random-init placeholder. Real convergence is blocked on:

1. **CTC loss** — frame-level cross-entropy plateaus at the uniform-distribution loss (~ln(96) ≈ 4.56) because there is no alignment signal between the input sequence and output characters. The CRNN architecture really wants Connectionist Temporal Classification: `candle-nn` does not ship CTC loss, so the next step is to implement CTC forward-backward (~150-200 LOC) and replace the frame-level CE in `train_with_candle.rs`
2. **Multi-hour training run** — once CTC lands, run `cargo run --release --example train_with_candle -- --epochs 100 --samples 50000 --batch-size 32 --lr 0.001` (target: CER < 5% on clean synthetic per `Phase 3` roadmap)
3. **Re-bundle** — replace `models/crnn-en.bin` with the trained weights and re-commit (the model file is regenerated by `examples/train_with_candle.rs` via the existing binary format)
